# Contributing

**Bug reports are welcome.** If something in the game does not work the way it should, [open an issue](https://github.com/Er2oneousbit/evermore2/issues/new/choose) with the bug report form. What helps most:

* what you did, what you expected, and what happened;
* your operating system and graphics card;
* the version and renderer from the debug overlay (press **F3** in the game: the top lines show both);
* the log file if something crashed or went wrong (`%APPDATA%\Godot\app_userdata\Secret of Evermore 2- Return to Evermore\logs\godot.log` on Windows, `~/.local/share/godot/app_userdata/...` on Linux);
* a screenshot, if it is something you can see.

This is a one-person project: pull requests and feature requests are not taken. The code is released under the [MIT License](LICENSE), so you are free to fork it and make your own version; the art keeps its own licenses (see [CREDITS.md](CREDITS.md)).
