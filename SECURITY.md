# Security

Secret of Evermore 2 is a single-player game: it has no accounts, no servers and no online features, and it does not send anything over the network.

If you find a security problem anyway (for example, a file the game loads that can be made to run code), please report it privately through [GitHub's security advisory form](https://github.com/Er2oneousbit/evermore2/security/advisories/new), not as a public issue. Only the latest version on `main` is supported.
